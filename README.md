# how-to-parse-recurrence-rule-at-server-side

## Repository Description
A sample ASP.NET project demonstrating how to parse the recurrence rule of the Essential JavaScript Scheduler on the server side.

## Project Overview
This repository contains a small example application that shows server-side handling of recurrence rules produced by the Essential JavaScript Scheduler. The sample illustrates parsing and interpreting recurrence rule strings so server logic can process, store, or transform scheduled events.

## Features
- Server-side parsing of scheduler recurrence rules
- Example ASP.NET web sample showing integration with a scheduler control

## Prerequisites
- Visual Studio (any recent version that can open ASP.NET projects)
- .NET development support and NuGet package restore

## Installation
1. Open the solution in Visual Studio.
2. Restore NuGet packages.
3. Build and run the sample web application.

## Usage
Run the sample and use the scheduler UI to create recurring events. The server-side example demonstrates how recurrence rule strings can be parsed and handled in application logic.
